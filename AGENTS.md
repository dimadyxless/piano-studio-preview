# Site maintenance

- This repository tracks the approved production website at https://virtuousofmusic.ru/.
- After each completed change, validate it, make a descriptive Git commit and push it to origin/main. Do not leave completed changes only on the local computer.
- Keep GitHub Pages disabled. GitHub stores the code; production runs on NetAngels.
- Preserve existing user changes and do not force-push.
- Before production updates, create a server backup outside the public web directory.
- Never commit SSH keys, credentials, private client documents, backup archives, or unsanctioned draft materials.
- Commit only files relevant to the completed change. Pending client approval is not authorization to publish drafts.
- Keep production metadata, sitemap, robots.txt and .htaccess consistent with the main domain.
