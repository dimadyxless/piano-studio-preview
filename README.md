# Музыка на кончиках пальцев

Актуальная опубликованная версия сайта: https://virtuousofmusic.ru/.
Размещение — NetAngels. GitHub Pages отключён; репозиторий служит для хранения
кода и истории изменений.

## Содержимое

27 HTML-страниц, CSS и JavaScript, изображения и видео, локальные шрифты и их
лицензии, favicon, sitemap.xml, robots.txt и правило перенаправления www в .htaccess.
Это готовый статический сайт; сборка и база данных для запуска не нужны.

Для локального просмотра из каталога репозитория:

```sh
python -m http.server 4191
```

Открыть http://localhost:4191/. Перенаправление .htaccess проверяется на хостинге,
локальный сервер Python его не исполняет.

## Порядок обновления

1. Сохранить резервную копию текущего сайта вне публичного каталога.
2. Внести согласованные изменения и проверить затронутые страницы и действия.
3. Сделать отдельный осмысленный коммит и отправить его в origin/main.
4. Загрузить изменённые файлы сайта на NetAngels по SSH/SFTP и проверить домен.

Файлы AGENTS.md, README.md и .gitignore предназначены для разработки, их не нужно
загружать в публичный каталог. Ключи и пароли хранятся отдельно от репозитория.
Автоматической публикации при push нет. Несогласованные черновики и исходные
личные документы клиента не входят в опубликованную версию.

Главный адрес — HTTPS без www. Canonical главной ведёт на /, остальные — на
собственные URL. robots.txt разрешает индексацию основного сайта.
Не включать GitHub Pages с этим robots.txt, чтобы не создавать индексируемый дубль.
